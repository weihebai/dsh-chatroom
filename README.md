# dsh-chatroom · 多人个人聊天室

[![test](https://github.com/dingchenhui0618-arch/dsh-chatroom/actions/workflows/test.yml/badge.svg)](https://github.com/dingchenhui0618-arch/dsh-chatroom/actions/workflows/test.yml)

在 DeepSeek Harness 里开一间屋子：**你**、**你带进来的 agent**，以及**局域网另一台机器上的人和它的 agent** 一起说话。
agent 不是「问一句答一句」的工具，而是屋里的成员 —— 有名字、有职责、有自己独立的会话历史。

DSH 原本是「你和一个会话」一对一。当你有三四个 agent、想让它们**在同一个上下文里互相看、互相补、你插话拍板**时，
缺的不是模型，是一间屋子和一套发言秩序 —— 这个插件补的就是这一层；再往前一步：**隔壁那台机器上的人也想带他的 agent 进来**，
于是有了 LAN 房间。

![房间面板](docs/panel.png)

**当前状态（诚实版）**：本机房间、三条并行发言规则、LAN 加入与跨机派发、本机授权（三档，默认只读）、
悬浮窗与未读提醒都已跑通；虎鲸颜色按房间落座，建屋与加入 LAN 都要自己挑。`npm test` **120/120**；
`docs/` 里 **19 张界面预览图 + 1 张真外壳截图都是真渲染**，两轮独立全量重跑逐字节相同；
真模型在真宿主里跑过一轮。逐条证据（含反证）在 [docs/VERIFICATION.md](docs/VERIFICATION.md)。

| 能力 | 一句话 |
| --- | --- |
| 一条消息叫多个 agent | 三条规则（@ 必回 / 全员一轮 / 主持人）可以**同时**开，一轮里每人只说一次 |
| agent 是成员，不是工具 | 名字与职责随时能改（职责进它每一次的提示词），各用自己原生的 session，记忆不串台 |
| 隔壁机器进来 | 地址 + 六位房间码，没有账号、没有注册；那边的人和 agent 标 `LAN · 机器名` |
| 跨机执行 | 轮到对面机器的 agent 时，这一轮**派回它那台**、用它本地的 session 跑完再回传 |
| 不让别人白使唤你的 agent | 本机授权三档：只读（默认）/ 授权后执行 / 完全授权 |
| 会话里的浮窗 | 可拖可折、带未读；收起成胶囊也带着「谁：最后一句」 |
| 一人一只虎鲸 | 八档颜色按房间落座：建屋、加入 LAN 都要先挑一档，同屋不撞色；成员列 / 消息 / 浮窗 / @ 候选同一只 |
| 让 AI 自己去群里交接 | 会话里的 AI 用 `chatroom` 工具发话、@ 另一个 agent 对接；活干完再发一条不 @ 人的「已完成」通知，只给人看 |
| 讨论不决就找你 | 房主可设「自动讨论几轮」；到顶还谈不拢，就在屋里 @ 你拍板，不再空转 |
| 清空记录 / 换会话 | 一键清掉屋里历史（成员规则保留）；也能让某个 agent 开新会话或回到上一个，避免旧上下文干扰 |
| 会话里直接问人 | 在活动会话里 @ 屋里某个成员或 agent，等它回一句，回复直接拿回来（私聊式，默认等 90 秒） |

## 安装

插件市场那条 `github:` spec 直接装，`--profile` 换成你的 profile：

```bash
dsh plugin --profile <你的profile> add github:dingchenhui0618-arch/dsh-chatroom
```

本机已经有这个仓库的目录时，也可以直接装目录：

```bash
dsh plugin --profile <你的profile> add D:\Projects\dsh-chatroom
```

装完刷新页面，侧栏出现「聊天室」。插件装好就会在 `4399` 监听（`DSH_CHATROOM_PORT` 可换端口）；
端口被占不影响本机房间，只是「邀请」里会写清原因、并告诉你怎么换。

- 仓库里已提交 `lib/index.js` 与 `lib/client.js`，**不用先构建**；`npm install github:…` 装进空目录后直接 `import` 得到 `name` / `inject` / `apply`。
- 包清单带了 `icon.svg` 与 `locale/{zh,en}.json`，插件管理页才有图标和中文名 —— `test/manifest.test.mjs` 盯着这条不过期。
- 上面那条命令是拿真 CLI 走通的：临时 `DSH_HOME` + `@deepseek-ai/dsh@0.2.2-rc.1`，4.7 秒装完 1 个包，
  `dsh.profile.bundles` 自动补上 `dsh-chatroom`，真起的 `dsh web` 页面加载的就是这个包的 `client.js`。
- 也可以用插件管理器装本地目录（`install_bundle`，target 指向包目录）。

![插件图标](docs/icon.png)

**插件图标**：64 栅格上的线性标记 —— 实心那间是「本机」，虚线那间是「跨机器」。一个 SVG，明暗主题都不换图。

## 用法

1. 侧栏 → **聊天室** → 新建房间：填房间名（和可选的主题），**挑一档虎鲸颜色**（不挑「建好」按不下去）。
2. 右栏 **＋ 加一个 agent**，给它名字和职责（职责会进它每次发言的提示词），填**工作目录**（这个 agent 干活的项目根目录，绝对路径；不填它会用默认目录、找不到你的项目），也可以在这间屋里给它挑一档颜色。改工作目录会让它换一个新会话（旧会话的记忆不延续）。
3. 说话。想点名就 `@名字`（输入 `@` 弹出成员列表），或者按 **让全员说一轮**。
4. 让另一台机器进来：右上 **邀请**，把地址和房间码发过去；对方在他的聊天室里 **加入 LAN 房间**，
   同样要先挑一档自己的颜色 —— 那台机器上的我，在这间屋里坐哪一档。
5. **授权**：右栏成员列底部三档，默认「只读」—— 它只管「别的机器派过来的回合要不要在这台机器上执行」，
   本机的人自己 @ 自己的 agent 不受影响。见 [本机授权](#本机授权)。
6. 会话界面标题栏右侧的「聊天室」开关拉起**悬浮窗**：可拖动、可折叠，Enter 直接发，位置会记住，
   双击标题栏回右下角；拖到边上会被夹回视口内，改窄窗口、重开页面之后它还在看得见的地方。

**让 AI 自己去群里交接**：先在房间里用面板建好一个 agent（比如「后端」），然后跟当前会话的 AI 说
「用『后端』的身份去群里 @ 前端，把接口交代清楚」。工具**不会自己新增成员**：它只用你已经建好的
那个 agent 身份发言；名字对不上就报错并列出可用的名字。消息里 @ 到谁，谁就在自己的会话里接着干。
活干完让它发一条 `notify`，就是一句不 @ 任何人的「已完成」，屋里所有人都看得到，但不会叫醒谁。

加入别人的屋子（LAN 房间）也照样能用：它用你本机那个 agent 的名字发言，消息转给宿主落库；
宿主只认这台机器报备过的 agent，署不了别人的名。以前版本给会话自动登记过成员的话，
用 `chatroom` 的 `leave` 动作可以把它们清掉。
`send` 默认会把用到的那个 agent 绑定到**当前会话**：之后房间 @ 它，回话落在你现在这个会话里（工作目录、上下文都对得上你的项目），不会跑到它早先自己开的旧会话去。`bind: false` 可以只发不绑。

### 本机

![刚装好、还没有房间的第一屏](docs/empty.png)

**刚装好的第一屏**：一间屋子都没有时也不留一块白 —— 一句话说清房间在谁那台机器上、另一台怎么进来
（地址 + 六位房间码），两个入口（新建 / 加入 LAN）当场可用，成员列整列收起，不占着一根空列。

![房间面板](docs/panel.png)

**房间面板**：左是房间列表与预览，底部「我的 agent」（这台机器带谁进屋）与「我的名字」；
中是群聊，`本机` / `LAN · 周荻的 MacBook` 的标记跟着消息走，新消息滚到底、自己翻历史时不打扰；
右是成员与规则入口。

![agent 的名字与职责可改](docs/agent-edit.png)

**agent 的名字、职责与它在这间屋里的颜色随时能改**：成员行上「改」→ 表单原地展开 → 保存。职责不是备注，
它会被写进这个 agent 每一轮的 prompt（`你的职责：…`）；颜色只改当前这间屋的座位，换屋子不改别处。

![新建房间要先挑颜色](docs/new-room.png)

**新建房间先挑一档虎鲸颜色**：表单里八档，没挑之前「建好」是灰的，旁边一行写着为什么 ——
每间屋的座位要自己选，不然一屋子人会全落在同一只白鲸上。

![三条规则并行](docs/rules.png)

**三条发言规则是并行开关**，不是三选一：被 @ 必回、全员各说一句、设主持人；
下面那条「每条最多引出 N 个回复」是共用的预算闸门。

![说完一句、谁都没接的时候](docs/no-reply.png)

**说完一句、谁都没接**：默认只开「被 @ 必回」，没点名的话不会有 agent 接 —— 界面在那句下面直接写清原因和
怎么写才叫到（`开头写 @名字，或者让全员说一轮`），agent 一接话它自己就消失，不会变成挂着的噪音。

![agent 没回上来时可以只重试它一个](docs/retry.png)

**agent 没回上来**：失败不悄悄消失 —— 占位消息留在房里（带错误码，灰色那行），底下「重试」只把**它**重跑一次，
不惊动其他 agent、也不换会话；这一轮还在发言时按钮按住。

![说满 200 句之后，更早的话还能翻回来](docs/history.png)

**说过的话翻得回去**：投影只带最近 200 条（房间能存 4000 条），所以列表顶端是「加载更早的消息」——
一页 100 条，翻到最早一条入口自己消失，视口停在原处；停在上头时底部浮出「回到最新」。

![翻着历史时屋里又进来话](docs/history-live.png)

**停在上头时屋里又进来话**：出口写「回到最新 · 2 条新的」，而且**不把人拽下去**；投影往前滑留下的接缝会按首句补上，
时间线才是连续的（这一屏拍的就是那个中间态）。

### 跨机器

![邀请另一台机器](docs/invite.png)

**邀请**：局域网地址 + 六位房间码就是全部凭据。装了 WSL / Hyper-V / 虚拟机的机器有好几个地址，
这里只把**最可能连得上**的放在上面，其余列在下面并标「虚拟网卡」—— 免得人抄一个本机自己通的 `172.x` 过去对着超时猜。

![加入方视角](docs/guest.png)

**同一间屋子，另一台机器上看到的视角**：它自己的人和 agent 不贴标签（本机就是默认），宿主的成员标
`LAN · 林岸的 MacBook`；规则与成员在宿主那台改，这边只能发言。

![加入失败](docs/join-error.png)

**加入失败时说人话**：地址写错、那台没开、码不对 —— 横幅写清「连不上 127.0.0.1:4599（对面那台没在监听这个端口）」，
不是 `fetch failed`；填过的地址和房间码还在表单里，不用从零重敲。

![三台机器同屋](docs/three-machines.png)

**三台机器同屋**：本机的人与 agent 不贴标，另外两台分别标 `LAN · 周荻的 MacBook` / `LAN · 陈默的 ThinkPad` ——
不是笼统一个「LAN」。这张不是摆拍：第三个进程真的握手、真的发言，宿主那句 `@库存 agent …` 也真的被派到第三台跑完再回传。

![加入之后才建的 agent 也能带进屋](docs/bring-agent.png)

**空手进来也能补**：新装的机器上一个 agent 都没有，所以左栏补了「我的 agent」—— 加入后再建也来得及，
建完立刻报给宿主，对面成员列当场多一个人，不用退出来重进；改名、改职责、删掉都跟着同步。

![两台机器的插件版本不一样](docs/old-peer.png)

**对面那台还是旧版本**：旧版本没有 `/lan/agents`，报不了 agent 名单 —— 而「没 agent」和「带不进来」看起来一模一样。
所以宿主不让人猜：成员列下面直接写清**哪台机器、缺什么、该做什么**（`旧版本，报不了 agent 名单 —— 重启那台的桌面端，再进屋一次`）。
这不是网络故障，重试没用：跑着的进程里是**装载那一刻**的代码。

![别的机器要在这台机器上跑一个回合](docs/approve.png)

**别的机器不能白使唤你的 agent**：LAN 派发把对端拼好的 prompt 原样交给本机 agent，而它用的是**本机配置的工具权限**。
所以每台机器有自己的授权档位（默认只读），挡的是「非本机的指挥」，详情见 [本机授权](#本机授权)。

### 浮窗、提醒与收尾

![悬浮窗](docs/float.png)

**会话界面里的独立悬浮窗**：标题栏右侧开关拉起，可拖可折，Enter 直接发；收起成胶囊以后同样拖得动、点一下才展开，
而且**收起时也带着最后一句**（`谁：说了什么`）与未读数 —— 不点开就知道值不值得点开。展开后是完整的一段对话，
和面板共用同一套消息行与输入器（头像、署名、机器名、时间、连说合组、跨天日期线、正在发言、重试、`@` 候选都在）。

![消息提醒](docs/notify.png)

**消息提醒**：新消息进来时侧栏图标、悬浮胶囊、标题栏开关都带未读数，右上角一条 toast，页面标题前缀同步成 `(1) …`。
这些数字会落回去：面板正停在那间屋子上、或者展开浮窗（都等于「看过了」）就推到最新一条；
面板被切走、标签页在后台时**不会**替你清，否则提醒就废了。

![宿主解散后的加入方](docs/gone.png)

**宿主把那间屋子解散了**：加入方的镜像不删，改成一条墓碑 —— 历史还在、标题栏标 `已解散`、输入框锁住，
右栏只留「从列表移除」。不这么做，加入方会卡在一个发不出话、也没有出口的房间里。

### 真外壳

![装进真的 DeepSeek Harness 之后的样子](docs/real-shell.png)

无头 Chrome 拿真 token 打开页面，然后**真的去点**：侧栏「聊天室」→ 建房 → 加一个 agent → 发一句。

### 界面规格

界面照 reactbits-pro 的三份 appui 源码重做（**Chat 1** 的频道列表 / 消息行 / 输入器、**AI Chat 6** 的成员与活动栏、
**AI Chat 5** 的授权卡），只把它的 neutral 灰阶换成宿主 token：近黑三层灰、1px 发丝线、
字号 11 / 12 / 13 / 14 / 15 五档、圆角 6 / 8 / 10 / 14 四档，选中一律用一层填充而不是描边。

- **颜色 / 间距 / 圆角先落 token**：`.cr-main` / `.cr-float` / `.cr-toast-wrap` / `.cr-approve` 上定义
  `--cr-fg / --cr-muted / --cr-body / --cr-caption / --cr-line / --cr-surface / --cr-fill-1..3 / --cr-accent / --cr-on-accent / --cr-r*`，
  组件里只引用变量；取值优先宿主 `--dsw-alias-*`，取不到才退回中性值 —— 明暗主题不需要各写一套。
- **间距只走 4/8 栅格**（4 / 8 / 12 / 16 / 24 / 32）。
- **正文列 780px 居中**：一行不拉成一千多像素的横条，输入器与它同宽对齐。
- **不做盒子套盒子**：房间行、成员行、分组标题都不画边框，靠填充与留白分层；选中的房间是 11% 填充，
  消息之间只留空白，自己说的话才有一块 14px 圆角的底。
- **鲸形标志**取自 DeepSeek Harness 应用图标的剪影（压成 96px 的 alpha 蒙版、用 `currentColor` 上色），
  出现在悬浮胶囊、浮窗标题、首屏说明与授权卡上。它是宿主自己的品牌标识，本仓库只是用它对齐宿主；
  要二次分发或单独发布，请换成自己的标志。
- **一人一只虎鲸**：每个成员的头像都是同一枚鲸形，颜色是**他在这间屋里的座位**（霜白 / 银灰 / 天蓝 / 青绿 /
  苔绿 / 琥珀 / 珊瑚 / 藕紫八档），成员列、消息行、浮窗、@ 候选里都是同一只 —— 认「这条是谁说的」不用先读名字。
  新建房间与加入 LAN 房间时**必须自己挑一档**（没挑按钮是灰的，旁边写着为什么）；加 agent 时也可以挑，
  不挑就由宿主给一档屋里空着的。换屋子就换成那间屋里我的颜色，改色只改当前这间屋；
  入口在左栏「我的名字」下面（我自己）与成员行内联表单（每个 agent）。
- **动效只在状态变化时出现一次**：消息落定抬 4px + 淡入 180ms、房间/成员 hover 150ms 过渡、
  发送键按下 0.97、胶囊 hover 抬 1px；其余不动，并尊重 `prefers-reduced-motion`。
- **两个抓手都能拖**：展开的标题栏与收起后的胶囊共用一套拖动（4px 阈值区分点击与拖动），拖动中夹在视口内，
  松手写 `localStorage`，双击标题栏回右下角。

### 这些图怎么来的

`docs/*.png` 由 `tools/preview/` 用无头 Chrome 截取（1440×900、2× 缩放）；预览服务器起两份预览页面
（3491 宿主 / 3492 加入方），第三台机器与「空手加入再补建 agent」那台各起一份 Store 与 LAN 监听、走真实协议按需加入。
外壳（左侧图标栏、会话标题栏、输入框）是**替身**，只为给真实尺寸与上下文，取色照 DSH 默认深色主题的**真 token**
（`#151517` 底 / `#f9fafb` 主文字 / `#2c2c2e` 抬起层 / `#ffffff0f` 发丝线），同名 `--dsw-alias-*` 摆在页面上。

为什么必须这样截：DSH 桌面端的窗口就是聊天界面本身，自动化不能截自己；而 `dsh web` 的会话 token 每个进程随机、不进磁盘，
外部浏览器拿不到。逐字节可复现的口径（钉层、未读清零、活倒计时、光标、镜像追平）和全部踩坑记录在
[docs/SCREENSHOTS.md](docs/SCREENSHOTS.md)。

## 三种发言规则

| 规则 | 行为 | 默认 |
| --- | --- | --- |
| 被 @ 必回 | 房间里谁 @ 了某个 agent，它一定回 | 开 |
| 全员轮次 | 你发一条，所有 agent 依次各说一句 | 关 |
| 主持人 | 设一个 agent 当主席：话先交给它，它回复里 @ 了谁就继续接给谁 | 关 |

三条同时开会撞车，所以有一条总预算：一条人消息最多引出 `maxSpeakers`（默认 3）个 agent 回合，
agent 之间接力最多 `maxDepth`（默认 2）层。预算烧完就停 —— 这是防止一屋子 agent 互相客套把 token 烧光的闸门。

预算之外还有两条硬规矩，都是为了「三条规则真的能同时开」：

- **一轮之内同一个人只说一次**。主持人 @ 了 B，全员轮次的队列里也有 B —— B 只说一句，
  预算不会被同一个人吃两遍，排在后面的人不会永远轮不到。
- **正在发言时你插的话不会被吞掉**。真实房间里一轮要好几秒，你正是在这时候补一句「@C 等会儿你单独说」；
  这句会排到这一轮结束后按同一套规则处理，而不是发了没反应。「停下这一轮」会清空排队，并用世代号挡住旧回合迟到的收尾。

## 两台机器怎么进同一间屋

**宿主那台**：面板右上「邀请」→ 看到 `地址:端口` 和房间码（形如 `10.0.51.18:4399` / `K7M2QD`）。
装了 WSL2 / Hyper-V 的机器上还会有 `172.x` 这类虚拟网卡地址：真实网卡排在前面，其余写在下面并标「虚拟网卡」。

**加入那台**：先填左栏底部的「我的名字」（这就是对面看到的名字），再点「＋ 加入 LAN 房间」→ 填地址和房间码。
不填名字也能进，只是两边都自称「我」的时候，宿主只能用机器名兜底称呼你。带进来的 agent 在加入那一刻一起进屋；
新装的机器上一个都没有，**加入之后再建也来得及**。

进来之后：

- 两边看到的是**同一间屋子、同一份 seq**；各自的人和 agent 标 `本机`，对方的标 `LAN · 机器名`；
- **名字随时能改**（左栏「我的名字」，回车或失焦生效）：宿主那边的成员列当场跟着换，历史消息保留当时的署名；
- **轮到对面机器上的 agent 说话时，宿主不会替它说**：宿主把这一轮派发过去，那台机器用**自己本地的原生 session**
  跑完再回传落库 —— 记忆长在它自己那台机器上，这才是「真人和他携带的 agent」；
- 45 秒没有回音就落一条失败占位（`某某这次没回上来`），这一轮不会卡死；对面正在**等你点「允许一次」**时会先把等待延长
  （最长 5 分钟），不会因为你在犹豫就落一条失败；
- 加入方的房间是**镜像**：规则、成员、解散都在宿主那台改，这边只能发言；
- **两边重启都认得回来**：宿主重启之前把这一组（人、他的 agent、他的椅子）记成席位落进状态，加入方拿同一条 link
  重新握手就坐回原来的成员 id —— 自己过去说的话还署在自己名下、已读不用重数、手上那一轮也跟着交给新那组跑完；
  加入方自己重启同理（link 落盘），不会出现两个「周荻」，也不会 @ 到幽灵；
- **对面关掉窗口或掉线**：掉线半分钟后整组撤掉，不留永远不回话的成员；正在长轮询、或正在跑模型的机器不算掉线；
- **对面那间屋子没了**（解散后又清了 profile、或地址上换了机器）：每 1.5 秒退避重试一次（不是打紧循环），
  同时标成离线并给出原因 —— 人看到的是「连不上、在重试」，不是界面一直转；
- **宿主解散屋子**：加入方留墓碑（历史还在、输入框锁住、可移除），解散那一刻还在跑的那一轮当场停掉。

**两台机器都得让进程装载过新代码**：补报名单用的是新接口。只刷新页面换的只是界面 —— 装完/更新完要**重启桌面端**，
或者在设置 → 插件里把 `dsh-chatroom` 关掉再打开。哪台没换过来，界面会直说（见 `docs/old-peer.png`），不用靠试。

连不上、或者怀疑两边跑的不是同一版代码时，先问一句探针（不需要房间码）：

```bash
curl -s http://10.0.51.18:4399/lan/ping
# {"ok":true,"value":{"ok":true,"hostMachine":"…","serving":true,
#   "code":{"version":"0.1.0","loadedAt":"…","appliedAt":"…","newestMtime":"…","stale":false}}}
```

`appliedAt` 是插件最近一次被装载/重载的时刻，`newestMtime` 是宿主文件在磁盘上最新的改动时间；`stale: true` 就是在说
「磁盘上已经有内存里没有的改动，得重载或重启」。判「换没换」要看 `appliedAt` 而不是 `loadedAt`：热重载只重新求值改过的模块。
探针每次都重新看磁盘，不是拿装载那一刻的快照。

想先验网络通不通（防火墙、网段、房间码），用自检脚本，不烧 token：

```bash
# 机器 A
node tools/lan-check.mjs host --port 4399
# 机器 B（按 A 打印的命令照抄）
node tools/lan-check.mjs guest --host 10.0.51.18:4399 --code K7M2QD
```

加入方那台会验两段路，两段都过才算出结果：① 我发一句 @ 对面那台的 agent → 它回一句；
② 我 @ 我自己带过去的 agent → 宿主把这一轮**派回我这台**、由它的原生会话跑完再回传（少这一段，「人带着自己的 agent 进屋」只是半条路）。

Windows 上连不上，先看入站防火墙。第一次监听时系统会问「允许访问」，选允许就够了 —— 但那条**程序级**规则只覆盖当时那个网络类型。
换了网络类型（家里 Wi-Fi 常是「专用」）、或当时点了取消，就补一条按端口的（不带 `-Profile`，三档都覆盖）：

```powershell
New-NetFirewallRule -DisplayName "dsh-chatroom" -Direction Inbound -Protocol TCP -LocalPort 4399 -Action Allow
```

## 本机授权

LAN 派发会把对端拼好的 prompt 原样交给本机 agent，而它用的是**本机配置的工具权限**。这是「带着自己的 agent 进屋」的前提，
但对只想进屋看看的人，这个默认值太激进 —— 所以每台机器有自己的授权档位（成员列底部，**默认「只读」**）：

| 档位 | 行为 |
| --- | --- |
| **只读**（默认） | 别处派来的回合**不执行**，屋里留一句说明（写清是哪一档拦的、去哪儿改） |
| **授权后执行** | 先弹授权窗口，本机的人点了「允许一次」才跑 |
| **完全授权** | 不问直接跑（还是本机自己的 agent、自己的会话，只是不问） |

门装在两处，因为是同一件事的两头：`speak.js` 里**由远程消息引出的本机 agent 回合**，以及 `lan-guest.runAssignment`
在 `runner.say()` **之前**（这是对端 prompt 直接进本机执行的那条路）。

- 窗口里写清**谁、哪台机器、要哪个 agent 做什么**，外加对方那句原话和完整请求（完整请求默认停在末尾，人不用先往下滚）。
- **fail closed**：不点、超时（默认 90 秒）、点「停下这一轮」、插件被关，一律按拒绝收尾 —— 宁可误拒，不可误执行。
  拒绝落一条 `notice` 而不是红色失败占位（重试也不会过，那是那台机器的选择，不是它坏了）。
- **本机的人自己 @ 自己的 agent 不受影响**：三种规则在本机内部照常直接生效，这道门只拦**非本机的指挥**；
  一次授权覆盖整轮（agent 之间接力沿用同一次授权）。
- 等授权期间不会被 45 秒的派发窗口打断：`ask` 的加入方弹卡前先 `POST /lan/hold` 把这一轮往后延（单次 ≤180s、总 ≤300s）。
- 加入方那台机器也有同一个开关 —— 它才是被要求执行的那一边；它拒了，宿主这边落一句说明。
- 档位只在本机、跟着 `state.json` 活下来，**不随房间投给对端**，也不能被对面改掉。

## 身份与来源

房间里成员分两种：**人** 和 **agent**。每个成员都带来源标记：

- `本机` —— 就在这台机器上（你、你的 agent）
- `LAN · 林岸的 MacBook` —— 从局域网另一台机器进来的（真人和他带来的 agent）

同一个标记出现在消息行、成员列表、悬浮窗三处，不靠颜色猜。机器名比 IP 好认，所以成员/消息上显示机器名，完整 IP 在悬浮提示里。

**颜色是「在这间屋里的座位」，不是身份**：每个人和他的每个 agent 在每间屋里各坐一档虎鲸色，
存在 `room.members[].color` 上。换一间屋就换一档（可以是同一个颜色，但那是重新挑的）；
人本身不带颜色，旧版本存在 `self` / `bots` 上的那两份读进来就抹掉，避免出现第二个真相。

- **建屋要挑**：新建房间的表单里八档、没挑之前「建好」是灰的。
- **进屋要挑**：LAN 加入表单里也有一排；挑的那一档对面已经有人坐着时，宿主回 `color_taken`，
  界面把话说明白（换一档再试），不会替你换掉。
- **同屋不撞色**：agent 由宿主任一档空着的；自己给自己改色时，别人坐着的那一档也点不动（同一个 `color_taken`）。
- 自动重连报的是「上次坐的那一档」，被占了就由宿主安排一档空的 —— 不为一个颜色把整条连接断掉。

八档的 id 只有宿主认识（`src/host/palette.js`），色值只在客户端（`lib/client.js` 的 `WHALE`），
换主题不必动任何人的 `state.json`；两张表对不对得上由 `test/palette.test.mjs` 盯着。

## 边界

这一版明确不做的事：

- **不做账号体系、不做公网多租户**：房间是「这台机器 + 你请进来的局域网机器」。LAN 用**明文 HTTP + 房间码**，
  威胁模型是「同一个 WiFi 下可信的人」，不是公网；要跨公网得走隧道（白名单中继），那是另一个决定。
- **对局域网开着的只有一个 HTTP 口，且它扛得住坏包**：不看 `Host` 头、请求行解析不了回 400、body 超过 256 KB 直接拒、
  任何漏出去的异常都在最外层兜住 —— 一个扫描器发什么都不会把宿主进程带走。但这不等于「防得住同网段的人」：
  **能连上 4399 的人就是能读屋里消息的人**，所以别在不可信的网络里开这个口。
- **成功响应里不发 CORS 放行头**：调用方只有另一台机器的插件进程和 `curl`，界面走同源 RPC。放行头没有用处，
  却会多一条「随便哪个网页都能读过本机聊天记录」的路 —— 这条有断言。
- **本机授权默认只读，是故意的**：新装的机器不替别人的话动本机工具权限。
- 不做附件、撤回、通知推送、手机端；加入方的镜像不能改规则、不能解散。
- 房间成员**不复用 dsh-bot**：那个插件的 peer 依赖钉在 `0.2.0-rc.2`，直接依赖会把本插件绑死。
  这里自带一层轻量 Bot 模型（具名 / 职责 / 独立 session 记忆），语义相同，等它稳了再谈适配。
- 完整的信任边界（谁能碰到什么、房间码强度与试错节流、落盘里有什么）写在 [docs/SECURITY.md](docs/SECURITY.md)；
  架构与决策写在 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

```bash
node tools/real-shell.mjs --url "<dsh web 打印的地址>" --out docs/real-shell.png   # 装进真 DSH 之后的样子
```

截图这件事有三条硬规矩，破了就会拿到一套「看起来对、其实不一样」的图：

- **每轮截图必须用刚起的预览服务器**（`/preview/writes` 为 0）。里面的状态机是活的，拿用过的状态再截，图和断言都会偏；
  脚本会自己先读 `/preview/writes`，非 0 就直接报错而不是默默截一套对不上 `docs/` 的图。
- **消息时间、房间码、LAN 端口、失败时的端口号全部钉死**，所以重跑只差抗锯齿噪点；否则 `docs/` 的 diff 看不出谁真改了界面。
- **带未读的几屏先等未读清零、加入方先等镜像追平**（`settle: 'read'` / `'mirror'`），活的东西（倒计时、闪烁光标、无限动画）
  在截图前钉住 —— 否则每次重跑都是一张不一样的图。

调某一屏时可以只跑它：`node tools/preview/shoot.mjs --only=history`（多屏用逗号）；整轮验收仍然不带参数全跑，
而且必须是刚起的服务器。完整口径在 [docs/SCREENSHOTS.md](docs/SCREENSHOTS.md)。
